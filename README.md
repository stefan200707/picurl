# 🏢 picurl — Умный генератор ссылок ПИК

[![Python 3.12+](https://img.shields.io/badge/python-3.12+-blue.svg)](https://www.python.org/downloads/release/python-3120/)
[![FastAPI](https://img.shields.io/badge/FastAPI-005571?style=flat&logo=fastapi)](https://fastapi.tiangolo.com)
[![uv](https://img.shields.io/badge/uv-Fast-purple.svg)](https://docs.astral.sh/uv/)

**picurl** — это микросервис, который переводит ваши текстовые запросы в готовые ссылки на квартиры. 
Вы пишете свободным текстом на русском языке, например: _«хочу двушку у метро, до 15 млн, с отделкой»_, а сервис возвращает рабочую ссылку на [pik.ru](https://www.pik.ru) с уже проставленными чекбоксами и фильтрами. Больше не нужно кликать вручную!

Парсинг полностью **детерминированный**: используются регулярные выражения (regex) и нечеткий поиск (rapidfuzz) по локальным JSON-справочникам. Никаких LLM или медленных внешних API в рантайме.

---

## 🚀 Быстрый старт (Запуск проекта)

Для работы сервиса требуется Python 3.12+ и пакетный менеджер [uv](https://docs.astral.sh/uv/).

### 1. Установка

Склонируйте репозиторий и установите зависимости:

```bash
uv sync
```

### 2. Запуск сервера

Запустите dev-сервер с автоматической перезагрузкой при изменении кода:

```bash
uv run fastapi dev
```
*(Альтернативная команда: `uv run uvicorn app.main:app --reload`)*

Сервер поднимется по адресу: **http://127.0.0.1:8000**

### 3. Как пользоваться

Своего визуального фронтенда у сервиса нет. Интерактивная работа с API происходит через встроенную Swagger-форму:

1. Откройте в браузере **<http://127.0.0.1:8000/docs>**
2. Раскройте метод `POST /build-url` и нажмите кнопку **Try it out**.
3. Введите ваш запрос в поле `text` (например: `"двушка на высоком этаже, до 20 лямов, без отделки"`).
4. Нажмите **Execute**.

**Пример успешного ответа:**
```json
{
  "url": "https://www.pik.ru/search/...",
  "criteria": {
    "rooms": ["2"],
    "price_max": 20000000,
    "finish": false,
    "not_first_floor": true
  },
  "result_count": 142,
  "warnings": []
}
```

## 🛠 Разработка и тестирование

### Запуск тестов
В проекте написаны unit и интеграционные (e2e) тесты.
```bash
uv run pytest
```

### Линтинг и форматирование кода
Проверка кода (ruff):
```bash
uv run ruff check
```
Автоформатирование кода:
```bash
uv run ruff format
```

### Обновление справочников
Справочники (метро, округа, районы, ЖК) лежат локально в `app/reference/*.json`.
Для обновления данных с открытого backend-API ПИКа выполните:
```bash
uv run python -m app.reference.refresh
```

## 📁 Структура проекта

```text
.
├── app/
│   ├── main.py            # Точка входа FastAPI, эндпоинт POST /build-url
│   ├── api/               # Pydantic-модели API (schemas.py)
│   ├── parsing/           # Логика извлечения фактов (regex) и fuzzy-матчинг
│   ├── reference/         # Локальные JSON-справочники + скрипт обновления
│   └── pik/               # url_builder (генератор URL) и validator (проверка)
├── tests/                 # Автоматические тесты (зеркалят структуру app/)
├── docs/                  # Документация (описание URL-схемы pik.ru)
└── prompts/               # Исходная декомпозиция задачи и промпты сборки
```
