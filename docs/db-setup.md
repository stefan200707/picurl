# Настройка подключения к базе данных

Проект использует PostgreSQL с расширением `pgvector` для работы Карты памяти (сохранение выводов ИИ, семантический кэш, предотвращение галлюцинаций).

## 1. Настройка переменных окружения (.env)

Сервис читает конфигурацию из файла `.env` в корневой директории проекта. Убедитесь, что в нем прописана строка подключения к БД, соответствующая настройкам из `docker-compose.yml`:

```env
DATABASE_URL=postgresql://postgres:password@localhost:5432/picurl_ai
```

## 2. Запуск базы данных (pgvector)

В проекте уже настроен `docker-compose.yml`. Поднимите БД командой:

```bash
docker compose up -d postgres
```

> **Примечание:** База данных будет доступна на локальном порту `5432`, имя базы `picurl_ai`, пользователь `postgres`, пароль `password`.

## 3. Накатывание миграций

Чтобы создать необходимые таблицы (`semantic_cache`, `ai_facts`, `district_facts`), нужно выполнить SQL-миграцию. 

Самый простой и надежный способ (выполнение скрипта внутри поднятого контейнера):

```bash
docker exec -i picurl-postgres psql -U postgres -d picurl_ai < app/ai/migrations/01_memory_tables.sql
```

*(Если у вас установлен локальный `psql`, можно также выполнить: `psql postgresql://postgres:password@localhost:5432/picurl_ai -f app/ai/migrations/01_memory_tables.sql`)*

## 4. Проверка подключения

После настройки и запуска проекта (`uv run fastapi dev`), база данных будет использоваться модулем ИИ-обогащения автоматически, сохраняя кэш и факты для последующего самообучения системы.
