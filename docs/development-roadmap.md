# Развитие picurl

1. **Точнее проверять выдачу.** Сверить валидатор с эндпоинтом сайта: нынешний `v2/filter` игнорирует часть фильтров. Результат — более надёжный `result_count`.
2. **Обновить справочники.** Проверить ID округов по реальной выдаче и исправить расхождения без потери GUID. Результат — рабочие фильтры локации.
3. **Сделать предупреждения понятнее.** Завершить категоризацию `warnings_detailed`, чтобы различать потерянные и неподдерживаемые условия.
4. **Улучшить геопоиск.** Обновить POI-кэш для новых категорий и проверить найденные объекты и расстояния.

Для каждого шага добавить проверочные запросы в тестовый корпус и сравнить готовую ссылку с карточками ПИК.
