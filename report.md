## Что реализовано в проекте (Milestone 5 достигнут)
Проект полностью собран и реализует заявленный функционал перевода свободного текста в URL сайта pik.ru:

1. **Каркас и API:**
   - FastAPI приложение с эндпоинтом `POST /build-url` и Swagger UI (`/docs`).
   - Контракты API (`BuildUrlRequest` и `BuildUrlResponse`).

2. **Модели и контракты:**
   - Зафиксирована спецификация URL-схемы.
   - Pydantic-модели `Criteria` (внутреннее представление фильтров).

3. **Справочники:**
   - Локальный JSON-слой данных (метро, районы, ЖК и т.д.).
   - Загрузка, кэширование и скрипт для обновления справочников.

4. **Парсинг и извлечение данных:**
   - **Regex-правила:** Функции извлечения цены, площади, этажа, отделки, сортировки и т.д.
   - **Fuzzy Matching:** Нечеткий поиск по справочникам через `rapidfuzz`.
   - **Фасад парсера:** Агрегирует извлечение и поиск, возвращая найденные критерии и собирая нераспознанный текст в `warnings`.

5. **Генерация URL и валидация:**
   - **URL-builder:** Трансформация `Criteria` в ссылку `pik.ru/search` с соблюдением правил single-путь/multi-query.
   - **Валидатор:** Сетевой запрос (best-effort) к API pik.ru для проверки наличия результатов (если ничего не найдено, отдается warning).

6. **Тестирование:**
   - Интеграционные end-to-end тесты с замоканным API полностью покрывают пайплайн.
