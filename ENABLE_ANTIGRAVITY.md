# Инструкция по использованию Antigravity и ИИ-обогащения в проекте

В данном проекте **Antigravity** (через Google Gemini) используется как провайдер для модуля **ИИ-обогащения**. 
ИИ-обогащение включается только тогда, когда детерминированный парсер (на базе регулярных выражений) не справляется со сложными контекстными или пространственными запросами (например, «квартира рядом с парком», «варианты в центре Москвы с хорошей экологией»). 

Чтобы полностью запустить ИИ-обогащение через Antigravity со всеми возможностями (включая Карту памяти на базе PostgreSQL и pgvector), выполните следующие шаги.

---

## Шаг 1. Настройка переменных окружения (`.env`)

Сервис использует `pydantic-settings` для чтения конфигурации из файла `.env`.
Создайте файл `.env` в корневой директории проекта и добавьте следующие настройки:

```env
# 1. Включение самого механизма ИИ-обогащения
AI_ENRICHMENT_ENABLED=true

# 2. Переключение провайдера на Antigravity
AI_PROVIDER=antigravity

# 3. Настройки Antigravity (v1, single shared login)
# Per-user подключения НЕТ: оператор один раз руками логинится в agy на этой машине.
# пусто = искать agy на PATH
ANTIGRAVITY_CLI_PATH=
# модель для agy задаётся общим полем AI_MODEL_NAME (по умолчанию gemini-3.5-flash)
AI_MODEL_NAME=gemini-3.5-flash

# 4. Подключение к базе данных PostgreSQL (для семантического кэша и фактов)
# (Данные соответствуют настройкам из docker-compose.yml проекта)
DATABASE_URL=postgresql://postgres:password@localhost:5432/picurl_ai
```

---

## Шаг 2. Запуск базы данных (pgvector)

Для работы Карты памяти (сохранение выводов ИИ, семантический кэш, предотвращение галлюцинаций) необходима база данных PostgreSQL с расширением `pgvector`.
В проекте уже настроен `docker-compose.yml`. Поднимите БД командой:

```bash
docker compose up -d postgres
```

> **Примечание:** База данных будет доступна на порту `5432`, имя базы `picurl_ai`, пользователь `postgres`, пароль `password`.

---

## Шаг 3. Накатывание миграций БД

Чтобы создать необходимые таблицы (`semantic_cache`, `ai_facts`, `district_facts`), выполните SQL-миграцию. 
Самый надежный способ (если у вас локально не установлен `psql`) — выполнить скрипт внутри контейнера:

```bash
docker exec -i picurl-postgres psql -U postgres -d picurl_ai < app/ai/migrations/01_memory_tables.sql
```

*(Если у вас установлен локальный `psql`, можно выполнить: `psql postgresql://postgres:password@localhost:5432/picurl_ai -f app/ai/migrations/01_memory_tables.sql`)*

---

## Шаг 4. Запуск проекта

Убедитесь, что все зависимости установлены (`uv sync`), и запустите сервер:

```bash
uv run fastapi dev
```

---

## Шаг 5. Как протестировать работу Antigravity

1. Откройте Swagger UI в браузере: http://127.0.0.1:8000/docs
2. Найдите эндпоинт `POST /build-url` и нажмите **Try it out**.
3. Введите сложный запрос, требующий пространственного мышления. Например:
   `"хочу двушку в центре с хорошими школами поблизости, до 20 лямов"`
4. Нажмите **Execute**.

В ответе вы должны увидеть, что ИИ успешно отработал:
```json
{
  "url": "https://www.pik.ru/search/...",
  "criteria": { ... },
  "warnings": [],
  "ai_used": true,
  "ai_cache_hit": false,
  "ai_explanation": "Подобраны ЖК в центральных районах с доступом к школам."
}
```
*Предупреждение «ИИ-обогащение выключено — часть запроса не обработана» больше появляться не должно.*

---

## Шаг 6. Самообучение ИИ (Promotion фактов)

В проекте реализован механизм, который переносит накопленные Antigravity знания из базы данных в быстрые локальные JSON-справочники. 
Если ИИ несколько раз подтвердил какой-то факт (например, что ЖК "Амурский парк" находится рядом с парком) с высокой уверенностью, этот факт можно "промоутить".

Для запуска процесса самообучения выполните команду:
```bash
uv run python -m app.ai.promotion
```
Скрипт проанализирует базу данных и обновит файлы в `app/reference/` и `app/knowledge_base/`, после чего эти факты будут использоваться детерминированно, минуя запросы к ИИ.

## Возможные проблемы (Troubleshooting)

1. **Пишет "ИИ-обогащение выключено — часть запроса не обработана"**
   - Проверьте, что в `.env` точно прописано `AI_ENRICHMENT_ENABLED=true`.
   - Убедитесь, что вы перезапустили сервер (`uv run fastapi dev`) после изменения `.env`.
   - Убедитесь, что установлен `AI_PROVIDER=antigravity` и вы авторизованы в `agy` (или правильно указали `ANTIGRAVITY_CLI_PATH`). (Если провайдер случайно остался `claude`, но нет ключа `ANTHROPIC_API_KEY`, система принудительно отключит ИИ).

2. **Ошибки подключения к PostgreSQL / таймауты ИИ**
   - Проверьте статус контейнера: `docker ps`.
   - Убедитесь, что строка `DATABASE_URL` в `.env` правильная. Модуль ИИ не упадет полностью без БД, но семантическое кэширование и долгосрочная память работать не будут.
