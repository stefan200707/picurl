# Руководство по настройке и запуску (SETUP.md)

В данном документе описано, как полностью настроить и запустить проект `picurl` для локальной разработки, включая детерминированный парсинг, ИИ-модули (Claude / Antigravity), базу данных pgvector и механизмы самообучения.

---

## 1. Системные требования

* **Python:** 3.12 или выше
* **Пакетный менеджер:** [uv](https://docs.astral.sh/uv/) (рекомендуется для быстрой и воспроизводимой установки зависимостей)
* **Docker & Docker Compose:** Для локального запуска базы данных PostgreSQL с расширением `pgvector` (требуется для работы векторного поиска и Карты памяти ИИ)

---

## 2. Установка зависимостей

Склонируйте репозиторий и перейдите в его корневую директорию. Установите все зависимости проекта:

```bash
uv sync
```

---

## 3. Настройка окружения (`.env`)

Сервис использует `pydantic-settings` для автоматического чтения конфигурации из файла `.env` в корне проекта.

Создайте файл `.env` (при необходимости скопировав с примера ниже):

```env
# -----------------------------------------------------------------------------
# 1. Защита служебных эндпоинтов
# -----------------------------------------------------------------------------
INTERNAL_REFRESH_TOKEN=your_super_secret_token_here

# -----------------------------------------------------------------------------
# 2. Настройки ИИ-обогащения (AI Enrichment)
# -----------------------------------------------------------------------------
# Включение ИИ-модуля (по умолчанию true)
AI_ENRICHMENT_ENABLED=true

# Провайдер ИИ: "antigravity" (Google Gemini) или "claude" (Anthropic)
AI_PROVIDER=antigravity

# Имя модели ИИ (по умолчанию gemini-3.5-flash)
AI_MODEL_NAME=gemini-3.5-flash

# Ключ Anthropic (требуется только если AI_PROVIDER=claude)
# ANTHROPIC_API_KEY=sk-ant-api03-...

# Настройки Antigravity (требуются если AI_PROVIDER=antigravity)
# ANTIGRAVITY_CLI_PATH=/path/to/agy
# Модель задаётся общим полем AI_MODEL_NAME выше (используется обоими провайдерами).

# -----------------------------------------------------------------------------
# 3. База данных PostgreSQL + pgvector (Карта памяти и векторный кэш)
# -----------------------------------------------------------------------------
DATABASE_URL=postgresql://postgres:password@localhost:5432/picurl_ai

# -----------------------------------------------------------------------------
# 4. Пороги промоушена знаний ИИ в детерминированные справочники
# -----------------------------------------------------------------------------
AI_PROMOTION_MIN_OBSERVATIONS=5
AI_PROMOTION_MIN_CONFIDENCE=0.8
```

---

## 4. Запуск Базы Данных (PostgreSQL + pgvector)

ИИ-слой сохраняет извлечённые факты и кэширует семантические эмбеддинги в базе данных с поддержкой векторного поиска.

### 4.1. Запуск контейнера PostgreSQL
```bash
docker compose up -d postgres
```

### 4.2. Накатывание миграций БД
Создайте необходимые таблицы (`ai_semantic_cache`, `ai_structured_facts`). 

Выполните миграцию через Docker-контейнер (не требует установленного утилиты `psql` на вашей системе):
```bash
docker exec -i picurl-postgres psql -U postgres -d picurl_ai < app/ai/migrations/01_memory_tables.sql
```

*(Если локально установлен `psql`, можно запустить: `psql postgresql://postgres:password@localhost:5432/picurl_ai -f app/ai/migrations/01_memory_tables.sql`)*.

---

## 5. Обновление справочников (Reference Data)

Проект использует локальные JSON-справочники (`app/reference/*.json`) для детерминированного парсинга без сетевых задержек.

### 5.1. Обновление основных справочников ПИК (ЖК, округа, районы, метро):
```bash
uv run python -m app.reference.refresh
```

### 5.2. Обновление гео-справочников POI (парки, школы, ТЦ из OpenStreetMap):
```bash
uv run python -m app.geo.refresh_poi
```

### 5.3. Динамическое обновление через HTTP API:
Сервис предоставляет защищенный эндпоинт `POST /internal/refresh-dicts`.  
Для его вызова передайте заголовок `X-Internal-Token`, совпадающий с `INTERNAL_REFRESH_TOKEN` из `.env`.

---

## 6. Запуск HTTP-сервера

Запустите dev-сервер FastAPI с автоматической перезагрузкой при изменении кода:

```bash
uv run fastapi dev
```

*(Альтернативная команда: `uv run uvicorn app.main:app --reload`)*

Приложение поднимется по адресу: **http://127.0.0.1:8000**

---

## 7. Использование и Swagger UI

Собственного фронтенда у сервиса нет. Интерактивное тестирование и вызов API производятся через открытый Swagger UI:

1. Откройте в браузере **http://127.0.0.1:8000/docs**
2. Перейдите к эндпоинту `POST /build-url` и нажмите **Try it out**.
3. Введите ваш текстовый запрос в поле `text`, например:
   `"хочу двушку у метро, до 20 млн, с отделкой, близко к центру"`
4. Нажмите **Execute**.
5. В ответе придет JSON со сформированной ссылкой `url`, распарсенными критериями `criteria`, количеством найденных квартир `result_count`, списком `warnings`, а также информацией об ИИ (`ai_used`, `ai_explanation`).

---

## 8. Самообучение и Промоушен знаний (Promotion)

Для анализа накопленных ИИ-фактов из PostgreSQL и автоматического переноса проверенных знаний в быструю локальную базу JSON-справочников запустите:

```bash
uv run python -m app.ai.promotion
```

Факты, подтверждённые `≥ AI_PROMOTION_MIN_OBSERVATIONS` раз с уверенностью `≥ AI_PROMOTION_MIN_CONFIDENCE`, записываются в `counties.json`, `districts.json` и `poi_cache.json`. В дальнейшем аналогичные запросы будут обрабатываться мгновенно и детерминированно, без сетевых вызовов к LLM.
