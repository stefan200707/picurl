# Руководство по настройке и запуску (SETUP.md)

В данном документе описано, как полностью настроить проект `picurl` для локальной разработки, включая базовый сервис парсинга, ИИ-модули и базу данных pgvector.

## 1. Системные требования

*   **Python:** 3.12 или выше
*   **Пакетный менеджер:** [uv](https://docs.astral.sh/uv/) (рекомендуется для быстрой установки зависимостей)
*   **Docker & Docker Compose:** Для локального запуска базы данных PostgreSQL с расширением pgvector (требуется для работы ИИ-обогащения)
*   **Утилита psql:** Клиент PostgreSQL (опционально, для ручного наката миграций)

## 2. Установка зависимостей

Склонируйте репозиторий и перейдите в его корневую директорию. Для установки всех зависимостей проекта выполните:

```bash
uv sync
```

## 3. Настройка окружения

Для полноценной работы проекта (включая обновление справочников и ИИ) вам могут потребоваться следующие переменные окружения (можно экспортировать их в терминале или использовать любой удобный вам способ управления env):

*   `DATABASE_URL` — строка подключения к базе данных PostgreSQL для асинхронного драйвера.
    По умолчанию (для локального Docker) используйте: `postgresql+asyncpg://postgres:password@localhost:5432/picurl_ai`
*   `ANTHROPIC_API_KEY` — ключ API для работы с моделями Anthropic (требуется для ИИ-обогащения запросов).
*   `INTERNAL_REFRESH_TOKEN` — секретный токен для защиты эндпоинта обновления справочников.

## 4. Настройка Базы Данных (ИИ и pgvector)

ИИ-слой сохраняет факты и кэширует ответы в базу данных с поддержкой векторного поиска.

**Запуск PostgreSQL:**

```bash
docker compose up -d postgres
```

**Накатывание миграций:**
После старта контейнера необходимо инициализировать таблицы. Выполните:

```bash
psql postgresql://postgres:password@localhost:5432/picurl_ai -f app/ai/migrations/01_memory_tables.sql
```
*(Обратите внимание: для CLI-утилиты psql используется стандартный протокол `postgresql://`)*.

## 5. Обновление справочников (Reference Data)

Проект использует локальные JSON-справочники для детерминированного парсинга. Некоторые из них обновляются напрямую с открытого API ПИКа.

**Обновление основных справочников (ЖК, округа, районы, метро):**
```bash
uv run python -m app.reference.refresh
```

**Обновление гео-справочников POI из OpenStreetMap:**
```bash
uv run python -m app.geo.refresh_poi
```

## 6. Запуск проекта

Запустить сервер разработки FastAPI с горячей перезагрузкой:

```bash
uv run fastapi dev
```

Или через uvicorn:

```bash
uv run uvicorn app.main:app --reload
```

Приложение будет доступно по адресу: **http://127.0.0.1:8000**

## 7. Использование

В приложении нет собственного фронтенда. Работа с сервисом происходит через встроенный интерфейс Swagger UI:

1. Откройте в браузере **http://127.0.0.1:8000/docs**
2. Найдите метод `POST /build-url` и нажмите **Try it out**.
3. Введите текст, например: `"хочу двушку у метро, до 15 млн, с отделкой"`.
4. Нажмите **Execute**.
5. Вы получите JSON с готовым URL, критериями, и, если подключен ИИ, полями вроде `ai_used` и `ai_explanation`.

## 8. Процесс разработки и тестирования

**Тестирование:**
Для запуска всех тестов (Unit и E2E), включая тесты ИИ (с моками сетевых запросов):
```bash
uv run pytest
```

**Проверка качества кода (Линтинг):**
```bash
uv run ruff check
```

**Автоформатирование кода:**
```bash
uv run ruff format
```

## 9. Продвижение знаний ИИ (Promotion)

Для анализа накопленных ИИ фактов в базе и переноса надежных утверждений (с высокой уверенностью и повторяемостью) в детерминированные JSON-справочники:

```bash
uv run python -m app.ai.promotion
```
Этот скрипт проверяет факты, и те, что преодолели порог (например, >= 3 наблюдения), добавляет в справочники `counties.json`, `districts.json` или `poi_cache.json`.
