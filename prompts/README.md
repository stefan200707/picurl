# Промпты для сборки `pik-url-builder`

Это набор готовых к применению промптов для пошаговой сборки проекта **picurl**
(`pik-url-builder`). Каждый файл — самодостаточная задача для одного агента:
контекст, цель, список файлов, требования к результату и критерии приёмки.

## Что строим

Сервис принимает свободный русский текст о желаемой квартире
(«хочу двушку у метро, до 15 млн, с отделкой») и возвращает рабочую ссылку на
`pik.ru` с применёнными фильтрами и сортировкой. Один эндпоинт: `POST /build-url`.

**Интерфейс:** своего фронтенда нет и не требуется — текст вводится через
автосгенерированную **Swagger-форму FastAPI на `/docs`** (бесплатно, часть самого
фреймворка): открываете страницу `/docs`, раскрываете `POST /build-url`,
нажимаете **Try it out**, вписываете желание в поле `text`, жмёте **Execute** —
и получаете JSON с готовой ссылкой на `pik.ru`.

**Ключевое архитектурное решение:** никаких вызовов LLM/внешних API в рантайме.
Весь парсинг — детерминированный (regex + rapidfuzz по локальным справочникам).
Единственный сетевой вызов на запрос — валидационный запрос к самому `pik.ru`.

## Общие конвенции (применяются во всех промптах)

Смотри `_conventions.md` — единый файл с требованиями к стеку, стилю, тестам и
обновлению `CLAUDE.md`. Каждый промпт ссылается на него; агенту следует прочитать
его перед началом работы.

## Как пользоваться

1. Прочитай `_conventions.md`.
2. Применяй промпты по порядку, по одному на агента/сессию.
3. После каждого шага прогоняй `verify` (линт + тесты), прежде чем идти дальше.
4. Открытые вопросы собраны в `_open-questions.md` — решай их по ходу
   соответствующего milestone и фиксируй принятое решение в `CLAUDE.md`.
