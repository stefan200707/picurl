# База Знаний ИИ (AI Knowledge Base)

Эта директория предназначена для хранения локальной "базы знаний", используемой искусственным интеллектом для улучшения качества парсинга запросов, запоминания контекста, гео-привязок и семантических ассоциаций пользователей.

## Планируемая структура и логика работы
При каждом сложном семантическом запросе (например, "квартира с детским садом неподалёку"), который обрабатывается ИИ:
1. Результаты внешних поисков (координаты садов, пересечения с ЖК ПИК, новые синонимы) сохраняются в этой базе.
2. База знаний будет содержать "веса" или "эмбеддинги" (embeddings) для концепций и фраз.
3. Перед каждым вызовом внешнего ИИ (LLM), локальный движок будет обращаться к этой базе. Если подобный паттерн уже встречался с высоким "весом" уверенности, система мгновенно ответит без вызова ИИ.
4. Со временем база знаний растет, система самообучается, и количество дорогих/медленных запросов к LLM стремится к минимуму.

См. подробности архитектуры в `docs/ai_architecture_proposal.md`.
