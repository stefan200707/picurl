# Инструкция: Подключение Antigravity (v1, single shared login)

В соответствии с требованиями для первой версии интеграции Antigravity в проект (v1), мы отказались от использования per-user подключения по API-ключам `GEMINI_API_KEY` в пользу единой разделяемой сессии через CLI `agy`.

Это означает, что **оператор проекта один раз вручную авторизуется на сервере** через браузерный OAuth, и все фоновые вызовы будут использовать эту сессию для обогащения запросов. 

## Что реализовано

1. Удалена зависимость от `GEMINI_API_KEY`.
2. Модуль `app.ai.client.call_antigravity` переписан на вызов локального бинарника `agy` с аргументом `--print` через `asyncio.subprocess`.
3. Добавлены новые переменные окружения:
   - `ANTIGRAVITY_CLI_PATH` — путь к бинарнику. Если оставить пустым, система будет искать `agy` в `PATH`.
   - Модель задаётся общим полем `AI_MODEL_NAME` (передаётся как `--model <имя>`), которое используется обоими провайдерами. Отдельная переменная `ANTIGRAVITY_MODEL` убрана (AUDIT_REPORT 1.4).

## Что требуется с вашей (оператора) стороны

Для того чтобы ИИ-обогащение заработало, выполните следующие действия на сервере/машине, где запущен `picurl`:

### Шаг 1. Авторизация в CLI
Запустите `agy` в интерактивном режиме один раз и пройдите процесс OAuth-авторизации:
```bash
agy
```
Вам будет предложено перейти по ссылке в браузере и авторизовать приложение. После успешной авторизации сессия будет сохранена локально.

### Шаг 2. Настройка `.env`
Обновите ваш `.env` файл. Переменная `GEMINI_API_KEY` больше не требуется. Убедитесь, что провайдер выбран верно:

```env
AI_ENRICHMENT_ENABLED=true
AI_PROVIDER=antigravity

# Укажите путь к исполняемому файлу agy, если он не проброшен в PATH.
# Например: /usr/local/bin/agy
ANTIGRAVITY_CLI_PATH=

# Укажите нужную модель (по умолчанию gemini-3.5-flash)
AI_MODEL_NAME=gemini-3.5-flash
```

### Шаг 3. Перезапуск приложения
После изменения `.env` и успешного логина в `agy`, просто перезапустите сервер `picurl`:
```bash
uv run fastapi dev
```

Всё! Теперь система обогащения будет формировать специальный prompt и вызывать `agy --print` без дополнительных UI-экранов авторизации для конечных пользователей.
